== Camel Example Main jOOR

This example shows using the `java` language in the Camel DSL, provided by the `camel-joor` component.
The language compiles the expression to Java once during startup (runtime), so it is very performant. It was
called the `joor` language until Camel renamed it to `java`; the DSL method is `java()`.

=== Build

First compile the example by executing:

[source,sh]
----
$ mvn compile
----

=== How to run

You can run this example using

----
$ mvn camel:run
----
